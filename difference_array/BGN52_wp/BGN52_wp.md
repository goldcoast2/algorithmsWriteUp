## 题目描述
对于给定的长度为 $n$ 的数组 $\{a_1, a_2, \dots, a_n\}$ ，我们有 $m$ 次修改操作，每一次操作给出三个参数 $l, r, k$ ，代表将数组中的 $a_l, a_{l+1}, \dots, a_r$ 都加上 $k$ 。
## 输入格式
第一行输入两个整数 $n, m(1 \leq n, m \leq 10^5)$ 代表数组中的元素数量、操作次数。

第二行输入 $n$ 个整数 $a_1, a_2, \dots, a_n(-10^9 \leq a_i \leq 10^9)$ 代表初始数组。

此后 $m$ 行，每行输入三个整数 $l, r, k(1 \leq l \leq r \leq n; -10^9 \leq k \leq 10^9)$ 代表一次操作。
## 输出格式
在一行上输出 $n$ 个整数，代表全部操作完成后的数组。
## 输入输出样例
**输入 #1**
```
3 2
1 2 3
1 2 4
3 3 -2
```

**输出 #1**
```
5 6 1
```

### ❌ 版本1：TLE（时间超限）

```python
n, m = map(int, input().split())     #元素数量和操作次数
an = list(map(int, input().split())) #n个整数 a₁, a₂, ⋯, aₙ
for _ in range(m):
    l, r, k = map(int, input().split())  #表示区间[l,r]各个元素+k
    #每次操作都要从l-1到r-1循环更新，时间复杂度太高，TLE
    for i in range(l-1, r):
        an[i] += k
 
print(*an)
```

**问题分析**：

每次操作都要从 `l-1` 到 `r-1` 循环更新。
- 单次操作的时间复杂度：**O(r - l + 1)** ≈ **O(n)**（最坏情况）
- m 次操作的总时间复杂度：**O(n × m)**

**知识点**：  
区间更新直接使用循环，在大数据量（如 n, m ≤ 10⁵）下必然超时。正确做法是使用**差分数组**将每次操作降为 O(1)，最后 O(n) 还原。

---

### ✅ 版本2：AC（正确）

```python
n, m = map(int, input().split())     #元素数量和操作次数
an = list(map(int, input().split())) #n个整数 a₁, a₂, ⋯, aₙ
#初始化差分数列，差分数列首项为原数列首项
diff = [0] * (n + 1)            
diff[0] = an[0]
for i in range(1, n):
    diff[i] = an[i] - an[i - 1]  #构造差分数列
for _ in range(m):
    l, r, k = map(int, input().split())  #表示区间[l,r]各个元素+k
    diff[l - 1] += k    #差分数列第l-1项+k
    diff[r] -= k        #差分数列列第r项+k
#初始化前缀和数列来还原，前缀和数列首项为原数列首项
score = [0] * n         
score[0] = diff[0]   
for i in range(1, n):
    score[i] = score[i - 1] + diff[i]    #用前缀和还原数列
print(*score)   #还原的数列就是所求数列

```

**核心技巧：差分数组**

- 用 O(n) 的时间把原数组 {aₙ} 构造成差分数组 {diffₙ}
- 其中 diff[0] = a[0]，diff[i] = a[i] - a[i-1]（i ≥ 1）
- 区间 [l, r] 每个数加 k 的操作转换为：
  - **diff[l-1] += k**
  - **diff[r] -= k**
- 单次更新 O(1)，最后用前缀和 O(n) 还原

## 复杂度对比

| 版本 | 时间复杂度          | 空间复杂度 | 结果 |
|------|----------------|-------|------|
| TLE | O(m × n) | O(n)  | ❌ 时间超限 |
| AC | O(n + m)       | O(n)  | ✅ 通过 |

## 补充说明

- **TLE 版本**：每次操作手写循环更新区间，时间复杂度 O(n × m) → TLE

- **AC 版本**：差分数组，单次更新 O(1)，最后 O(n) 还原，时间和内存都最优

---

## Python 小贴士

> `for i in range(l-1, r): an[i] += k` 写起来很直观，但区间更新用循环，大数据量慎用。

> **差分数组** = O(n) 预处理 + O(1) 区间更新 + O(n) 还原的经典思想。

---

## 一句话总结

**差分数组 = 用空间换时间，用预处理换区间更新速度。**
