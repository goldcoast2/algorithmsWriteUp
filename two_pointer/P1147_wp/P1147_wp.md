## 题目描述

给定一个正整数 $M$，求出所有的连续的正整数段（每一段至少有两个数），使得这些连续的正整数段中的全部数之和为 $M$。

例如，$1998+1999+2000+2001+2002=10000$，所以从 $1998$ 到 $2002$ 的一个正整数段为 $M=10000$ 的一个解。

## 输入格式

输入一行一个正整数，表示 $M$ 的值（$10\le M\le 2\times 10^6$）。

## 输出格式

输出每行包含两个正整数，表示一个满足条件的连续正整数段的左右端点，两数之间用一个空格隔开。

输出按左端点大小升序排列。

## 输入输出样例 #1

### 输入 #1

```
10000

```

### 输出 #1

```
18 142 
297 328 
388 412 
1998 2002

```

### ✅ 版本1：数学解法AC

```python
import math   #导入math库
M = int(input())  #正整数的值
limit = int(math.sqrt(2 * M))  #最大可能取值，这是一个等差数列求和公式
res = []               #列表存储数据
#从小到大依次尝试，中间部分是数学推导出来的
for y in range(2, limit + 1):
    if (2 * M) % y == 0:
        x = (2 * M) // y
        if x > y and (x - y + 1) % 2 == 0:
            a = (x - y + 1) // 2
            res.append((a, a + y - 1))
res.sort()#排序
for l, r in res:
    print(l, r)   #输出答案
```

## 核心技巧：数学解法

- 设连续自然数段为**a, a+1, a+2, ..., a+y-1**,其中a是首项,y是项数

- 等差数列求和**S=(2a+y-1)×y÷2=M**

- 令**x=2a+y-1**，则**x×y=2M**,其中**x>y≥2**,且**x-y+1**是偶数

- 原因：由**x=2a+y-1**得到**a=(x-y+1)÷2**，又因为a为整数，所以**x-y+1**为偶数

- 所以y最大值取**2M^(1/2)**


**知识点**：等差数列，数论

### ✅ 版本2：同向指针AC（正确）

```python
M = int(input())   #正整数的值
left, right = 1, 1 #初始化左右指针
s = 0      #当前窗口所有数的和，初始为0
#右指针最大为M
while right <= M:
    #和小于M，放大窗口，右指针右移，总和加上右指针指向的值
    if s < M:
        s += right
        right += 1
    #和大于M，缩小窗口，左指针左移，总和减去左指针指向的值
    elif s > M:
        s -= left
        left += 1
    #和等于m，左右指针相差如果大于2，输出数对，总和减去左指针指向的值，左指针左移
    else:
        if right - left >= 2:
            print(left, right - 1)
        s -= left
        left += 1
```
## 核心技巧：同向双指针
- 在**线性结构（数组、字符串）**中，定义两个指针 `left` 和 `right`，都从同一端（通常是左端）开始，向同一方向移动，维护一个**窗口**区间 `[left, right]`
- 通常用于：
  - **子数组/子串问题**：求满足条件的最长/最短连续子数组
  - **固定和问题**：如寻找和为定值的连续子序列
  - **字符串匹配**：最小覆盖子串、无重复字符最长子串
  - **计数问题**：统计满足条件的子数组个数
- 核心原理：利用单调性，不满足条件时移动 `right` 扩大窗口，满足条件时移动 `left` 缩小窗口，每个元素最多被每个指针访问一次
- 时间复杂度 **O(n)**，空间复杂度 **O(1)**

### ✅ 版本3：前缀和+同向指针AC（正确）

```python
M = int(input())       #正整数的值
# 构造前缀和数组
pre = [0] * (M + 2)
for i in range(1, M + 1):
    pre[i] = pre[i-1] + i
#设置左指针和又指针
left = 0
right = 1
# right 最大到 M，且保证左指针小于右指针
while left < right and right <= M:  
    current_sum = pre[right] - pre[left]
    #如果等于给定正整数的值
    if current_sum == M:
        # 至少要两个数，所以 right - left >= 2
        if right - left >= 2:  
            print(left + 1, right)#输出两个端点
        left += 1  # 移动左指针继续找
    #如果小于M，右指针移动
    elif current_sum < M:
        right += 1
    #如果等于M，左指针移动
    else:
        left += 1
        #当 left 追上了 right，需要重置 right
        if left >= right:
            right = left + 1
```
## 核心技巧：前缀和
- 所有求区间和的题目，都可以使用前缀和来解决

## 复杂度对比

| 版本         | 时间复杂度 | 空间复杂度 | 结果 |
|------------|-------|-------|-----|
| 数学方法 AC    | O(√M) | O(1)  | ✅ 通过 |
| 同向指针 AC    | O(M)  | O(1)  | ✅ 通过 |
| 前缀和同向指针 AC | O(M)  | O(M)  | ✅ 通过 |
**补充说明**

- 数学方法AC 版本：只需要枚举 y 从 2 到 √(2M)，每次 O(1) 判断 →时间复杂度O(√M)

- 同向指针AC 版本：right 指针从 1 移动到 M，left 指针也从 1 移动到 M，每个指针最多移动 M 次，总共约 2M 次操作 →时间复杂度O(M)

- 数学方法AC 版本：单层循环O(M)时间复杂度+预处理前缀和数组O(M)空间复杂度

> 同向指针除了这种速度一样的还有一种**快慢指针**，左右两个指针速度不一样，用于判断是否有环

## 一句话总结

**在序列上维护两个同向移动的指针 `left` 和 `right`，通过扩大窗口（`right+1`）或缩小窗口（`left+1`）来动态调整区间，使每个元素最多被访问两次，将暴力枚举的时间复杂度从 O(n²) 降至 O(n)**
