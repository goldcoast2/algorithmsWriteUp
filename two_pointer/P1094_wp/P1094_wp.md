## 题目描述

元旦快到了，校学生会让乐乐负责新年晚会的纪念品发放工作。为使得参加晚会的同学所获得的纪念品价值相对均衡，他要把购来的纪念品根据价格进行分组，但每组最多只能包括两件纪念品，并且每组纪念品的价格之和不能超过一个给定的整数。为了保证在尽量短的时间内发完所有纪念品，乐乐希望分组的数目最少。

你的任务是写一个程序，找出所有分组方案中分组数最少的一种，输出最少的分组数目。

## 输入格式

共 n+2 行：

第一行包括一个整数 w，为每组纪念品价格之和的上限。

第二行为一个整数 n，表示购来的纪念品的总件数 G。

第 3∼n+2 行每行包含一个正整数 Pi 表示所对应纪念品的价格。

## 输出格式

一个整数，即最少的分组数目。

### ✅ 正确版本：左右指针＋贪心（最优）

```python
w = int(input())    #每组纪念品价格之和的上限
n = int(input())    #购来的纪念品的总件数
prices = []         #存储价格
for _ in range(n):
    prices.append(int(input()))  #输入价格
prices.sort()      #排序
#设置左右指针及目标答案
left = 0
right = n - 1
ans = 0
#当左指针小于右指针时，如果左右指针所对应的数加起来小于等上限，左指针往右，右指针往左
while left <= right:
    if prices[left] + prices[right] <= w:
        left += 1
        right -= 1
    #否则只有右指针往左
    else:
        right -= 1
    #每轮循环都将答案＋1
    ans += 1
print(ans)           #输出最后的结果
```

## 核心技巧：贪心＋左右指针

- 将数组**排序**后，使用左指针指向最小值，右指针指向最大值
- 根据问题约束（如两数之和不超过上限），决定是**配对移动**（左右指针同时向中间移动）还是**单边移动**（仅右指针左移）
- 通常用于**分组、配对、覆盖**等最优化问题，需要满足**贪心选择性质**：局部最优决策能推导出全局最优解
- 时间复杂度为 **O(n log n)**，其中 n log n 来自排序，双指针遍历部分为 O(n)
- 与普通双指针的区别：
  - 普通双指针：通常在**未排序或已排序数组**中寻找满足特定条件的**一对元素**（如两数之和等于 target）
  - 贪心+左右指针：在**排序后**利用**极值配对策略**，通过**贪心决策**逐步缩小搜索范围，最终得到**全局最优的分组/配对数量**

## Python 小贴士

> 在贪心+左右指针的题目中，**数组必须先排序**，才能利用极值配对策略（最贵配最便宜），否则贪心不成立

> 贪心+左右指针是对“排序后的数组”用对撞指针逐步缩小范围，而非在原始数组上直接操作

---

## 一句话总结

**贪心+左右指针的核心：排序后，最贵的优先尝试与最便宜的配对，能配则带走两个，否则只带走最贵的。**
