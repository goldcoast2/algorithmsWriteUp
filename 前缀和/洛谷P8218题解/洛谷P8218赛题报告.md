## 题目描述
给定由 n 个正整数组成的序列 a₁, a₂, ⋯, aₙ 和 m 个区间 [lᵢ, rᵢ]，分别求这 m 个区间的区间和。
## 输入格式
第一行包含一个正整数 n，表示序列的长度。

第二行包含 n 个正整数 a₁, a₂, ⋯, aₙ。

第三行包含一个正整数 m，表示区间的数量。

接下来 m 行，每行包含两个正整数 lᵢ, rᵢ，满足 1 ≤ lᵢ ≤ rᵢ ≤ n。
## 输出格式
共 m 行，其中第 i 行包含一个正整数，表示第 i 组答案的询问。
## 输入输出样例
**输入 #1**
```
4
4 3 2 1
2
1 4
2 3
```

**输出 #1**
```
10
5
```
## 说明/提示
**样例解释**

第 1 到第 4 个数加起来和为 10。第 2 个数到第 3 个数加起来和为 5。

**数据范围**

- 对于 50% 的数据：n, m ≤ 1000
- 对于 100% 的数据：1 ≤ n, m ≤ 10⁵，1 ≤ aᵢ ≤ 10⁴


### ❌ 版本1：MLE（内存超限）

```python
n = int(input())
a = list(map(int, input().split()))
m = int(input())

for _ in range(m):
    l, r = map(int, input().split())
    total = sum(a[l-1:r])
    print(total)
```
**问题分析**：

a[l-1:r] 会创建一个切片副本。

- 区间长度 50000 时，一次切片就复制 50000 个整数

- m 次查询 → 内存反复分配 → MLE

讲的是：空间复杂度 + Python 切片机制

### ❌ 版本2：TLE（时间超限）

```python
n = int(input())
a = list(map(int, input().split()))
m = int(input())

for _ in range(m):
    l, r = map(int, input().split())
    s = 0
    for i in range(l-1, r):
        s += a[i]
    print(s)
```

**问题分析**：

每次查询都要从 l 到 r 循环累加。
- 单次查询时间复杂度：O(n)
- m 次查询总时间复杂度：**O(n × m)**
- 当 n = 100000, m = 100000 时 → **100 亿次加法操作**

**知识点**：两层循环嵌套在大数据量下必然超时。

---

### ✅ 版本3：AC（正确）

```python
n=int(input())
a=list(map(int,input().split()))
m=int(input())
pre=[0]*(n+1)
for j in range(n):
    pre[j+1]=pre[j]+a[j]
for _ in range(m):
    l,r=map(int,input().split())
    print(pre[r]-pre[l-1])
```

**核心技巧：前缀和**

- 用 O(n) 的时间把原数组 {aₙ} 构造成前缀和数组 {Sₙ}
- 其中 Sₖ = a₁ + a₂ + ... + aₖ
- 区间 [l, r] 的和 = **S[r] - S[l-1]**，单次查询 O(1)

## 复杂度对比

| 版本 | 时间复杂度          | 空间复杂度 | 结果 |
|------|----------------|-------|------|
| MLE | O(m×k)         | O(n)  | ❌ 内存超限 |
| TLE | O(m×k) | O(n)  | ❌ 时间超限 |
| AC | O(n + m)       | O(n)  | ✅ 通过 |
**补充说明**
- MLE 版本：每次查询用 sum(a[l-1:r])，切片会复制子数组，内存瞬间飙升 → 直接 MLE

- TLE 版本：每次查询手写循环累加，内存稳定但时间爆炸 → TLE

- AC 版本：前缀和，时间和内存都最优
## Python 小贴士

> `sum(a[l-1:r])` 写起来很优雅，但切片会复制，大数据量慎用。

> 前缀和是 O(n) 预处理 + O(1) 查询的经典思想。

## 一句话总结

**前缀和 = 用空间换时间，用预处理换查询速度。**
